# Upstream attribution

This Git-only package adapts portions of two upstream implementations for the user's Pi setup:

- Ben Davis, [`davis7dotsh/my-pi-setup`](https://github.com/davis7dotsh/my-pi-setup), `extensions/subagents`: Effect-based headless Pi, Claude Code, and Codex backends, normalized lifecycle manager, deferred result delivery, transcript UI, and takeover UI.
- Modem, [`modem-dev/pi-herdr-subagents`](https://github.com/modem-dev/pi-herdr-subagents): Pi-native subagent definition compatibility and the boxed, width-aware running-subagents widget design.

Additional architecture references:

- Pi's bundled native subagent extension example in `@earendil-works/pi-coding-agent`.
- AgwaB's `pi-subagent` and `pi-workflow` public documentation for role discovery, execution routing, artifact boundaries, and deterministic orchestration.

See [NOTICE.md](./NOTICE.md) for the unlicensed status and copied/adapted-source attribution. The repository is public for Git access, but it is not an npm package.
