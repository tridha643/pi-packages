# Upstream attribution

This private local package began from two implementations inspected and adapted for the user's Pi setup:

- Ben Davis, `davis7dotsh/my-pi-setup`, `extensions/subagents`: Effect-based headless Pi, Claude Code, and Codex backends, normalized lifecycle manager, deferred result delivery, transcript UI, and takeover UI.
- Modem, `modem-dev/pi-herdr-subagents`: Pi-native subagent definition compatibility and the boxed, width-aware running-subagents widget design.

Additional architecture references:

- Pi's bundled native subagent extension example in `@earendil-works/pi-coding-agent`.
- AgwaB's `pi-subagent` and `pi-workflow` public documentation for role discovery, execution routing, artifact boundaries, and deterministic orchestration.

The vendored upstream checkouts available during development did not include license files. This repository is therefore private and marked `UNLICENSED`; it should not be redistributed until upstream licensing is confirmed.
